# 年假与请假升级

实现位于功能分支。两份云端 SQL 已完成人工审阅并于 2026-10-22 部署到生产项目 `mwoqpheguldiuemgztkk`，部署后完整快照为 75 条加班/调休、0 条年假、365 条 2026 日历；未写入业务测试夹具。

## 部署顺序

1. 用旧版导出并校验 ZIP；另保留 Supabase 数据库备份及 Storage 照片副本。
2. 审阅并人工执行 `docs/supabase_cloud_ledger.sql`，使加班保存和删除也先取得统一账本事务锁。
3. 审阅并人工执行 `docs/supabase_annual_leave.sql`。它新增独立年假表、全年日历、可选事由、完整快照与事务 RPC，并升级旧调休 RPC 的校验。脚本用一个事务包裹，不修改历史记录；2026 日历沿用项目已有的 2026.1 配置。
4. 只读检查 `get_leave_ledger_snapshot()` 返回原加班/调休记录、年假数组和 365 条 2026 日历；对照部署前 UUID、记录内容、照片引用和加班余额。不要用测试夹具向生产库写入。
5. SQL 部署后在隔离测试项目或本机数据库完成下述回归，再使用调试 flavor 验证设备界面；生产验收采用用户正常业务操作，最后才发布正式 APK。

新应用依赖完整快照 RPC。客户端发布前仍需确认完整快照可读并保留缓存安全行为。没有发布授权时不升版本、不合并主分支或推送主分支。

## 业务约定

从 2026 年起，按每个请假年度单独计算 5 天额度，不创建会重复发放的年度加班记录。年末结余过期，不结转；允许补录往年，编辑和删除也只改变该年的账本。半天固定为 0.5 天，上午占用 08:30–11:30，下午占用 12:00–17:00，午休不占用。范围内跳过休息日，跨年拆分登记。

统计页同一行分别展示可用调休小时数和当前年度可用年假天数。年假年度额度、已用天数和结转规则通过 Tooltip 说明；历史记录仍可在筛选和详情中查看。两种假别都可填事由、预览、直接编辑和删除。调休时间不变时保留原核销来源；时长变化时返还本条旧扣减，再按当前库存重跑 FIFO。来源或金额与预览不符、余额不足时整笔回滚。

## 数据与兼容

- SQLite v1 → v2：先 checkpoint 并保存 `pre-schema-1-to-2-*/database.db`，再事务新增事由列和年假/日历表。未知版本失败，不重建。升级不修改照片；恢复点保存旧版数据库，禁止直接降级打开 v2。
- 同步通过一个 SQL 语句读取三部分完整快照，不受表查询默认分页条数限制。完整校验后才事务替换 SQLite；意外空账本或丢失已有年度日历时保留原缓存。删除年假取得明确云端确认后定向移除该缓存行，不使用空响应清库。
- ZIP v2 包含 `annual_leave.json`、`leave_calendar.json` 及逐文件 SHA-256；继续读取 v1，并保持旧记录没有事由时的原指纹算法。v1 恢复不删除既有年假。云端恢复通过单一 RPC 按 UUID 合并两类账本，验证合并后的核销引用、年度额度和时段冲突。
- 云端恢复前保存数据库和照片恢复点。请求超时后无法确认提交状态时保留已上传照片；仅在重新读取快照并确认未被引用后清理。
- 新表启用 RLS，显式给予 anon 读取权限；年假写入策略要求事务 RPC 设置的本地上下文。延续当前单人匿名账本，不引入用户认证。RPC 使用 `SECURITY INVOKER`，不在客户端放入 service role key。

## 后续年度日历

审阅官方年度安排后，人工向 `leave_calendar` 写入该年每一天的 `date / is_day_off / calendar_version`。必须包含全年 365 或 366 个不重复日期，调班周末也须正确标记。未完整更新的年份，客户端和 RPC 都拒绝登记年假；完整同步后自动可用，无需更改 5 天额度规则。

## 本机验证

```bash
flutter test
flutter analyze
```

RPC 回归脚本只创建临时隔离库，不接受生产连接字符串。使用 Node.js 安装临时测试运行时（不修改 Flutter 依赖）：

```bash
npm install --prefix /tmp/obf-sql-runtime embedded-postgres@18.4.0-beta.17
EMBEDDED_POSTGRES_MODULE=/tmp/obf-sql-runtime/node_modules/embedded-postgres/dist/index.js \
  node tool/test_cloud_ledger.mjs
```

脚本只监听回环地址，端口动态分配，结束后关闭并删除测试库。覆盖年假额度、范围、半天、编辑、RLS、完整快照、调休返还/FIFO、双向冲突、恢复回滚，以及两个真实连接争用最后 1 天。也可用 PGlite 运行单连接校验，但它不代替真实并发测试。

设备验收仍需在人工部署 SQL 后进行：登记半天及多日年假、编辑年假和调休、删除返还、ZIP 换机恢复、断网只读和覆盖升级。生产 SQL、设备安装、正式 APK 发布是独立状态，不能用本机测试通过代替。
